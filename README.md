## FAIR in a nutshell

| Principle | Summmary |
|-----------|-------------------------------------|
| **F**indable | Does (meta)data have a persistent identifier (e.g. a DOI) and rich metadata that is indexed somewhere searchable? |
| **A**ccessible | Can people (and machines) retrieve (meta)data through a standard protocol, and is the metadata available even if the data itself is restricted? |
| **I**nteroperable | Does (meta)data use open, community-standard formats and controlled vocabularies? |
| **R**eusable | Does (meta)data have a clear license, provenance, and enough documentation for someone else to understand and reuse it? |
